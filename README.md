# Portfolio Website with CI/CD Pipeline

This project is a personal portfolio website integrated with a basic CI/CD pipeline using Jenkins, Docker, and GitHub.

The website showcases my profile, skills, projects, and contact information, while the CI/CD workflow automates the build and deployment process.

## Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### DevOps Tools
- Git & GitHub
- Docker
- Jenkins
- Linux

## Features
- Responsive portfolio website
- GitHub Pages deployment
- Docker containerization
- Jenkins CI/CD pipeline
- Automated build and deployment workflow

## Live Website
https://tanushree-paul.github.io/Portfolio/

## CI/CD Workflow
GitHub Repository → Jenkins Pipeline → Docker Build → Container Deployment

## Project Setup

### Clone Repository
git clone https://github.com/Tanushree-Paul/Portfolio.git

### Build Docker Image
docker build -t portfolio .

### Run Docker Container
docker run -p 8080:80 portfolio

## Jenkins Pipeline
The Jenkins pipeline automates:
1. Pulling latest code from GitHub
2. Building Docker image
3. Running Docker container

## Learning Outcome
Through this project, I learned:
- CI/CD concepts
- Docker containerization
- Jenkins pipeline automation
- GitHub integration

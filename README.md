# Portfolio Website

This project is a personal portfolio website integrated using GitHub.

The website showcases my profile, skills, projects, and contact information.

## Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

## Features
- Fully responsive design for different screen sizes
- Dynamic UI features using JavaScript
- DOM manipulation and event handling
- Project section with GitHub links and descriptions
- Resume download functionality
- Structured contact section
- Clean and user-friendly interface
